# Welcome to SimpleBlog

This is a **sample** post used by the test-suite. It demonstrates that Markdown
is rendered to HTML with Pandoc and wrapped in a Jinja2 template.

## A section

- supports lists
- supports `code`
- supports $E = mc^2$ math when `--mathml` is enabled
